# Журнал утверждённых решений проекта

## Решение LM-PORTABLE-001 — автономный запуск Library Manager 1.8

- Статус: **УТВЕРЖДЕНО**
- Дата фиксации: 2026-11-19
- Область: POP PUNK GUITAR LIBRARY MANAGER 1.8, Windows x64.

### Утверждённые требования

1. Целевая система — Windows 10 x64.
2. Пользовательская версия распространяется как Portable ZIP с папкой приложения (onedir), а не как исходный Python-проект.
3. На компьютере пользователя не требуется установленный Python, pip, виртуальное окружение или установка аудиобиблиотек.
4. В дистрибутив включаются собственный Python Runtime, необходимые DLL, аудиодекодеры, ресурсы и зависимости.
5. Пользователь распаковывает архив и запускает `POP_PUNK_GUITAR_LIBRARY_MANAGER.exe` двойным щелчком из папки приложения.
6. EXE нельзя отделять от остальных файлов дистрибутива.
7. `BUILD_PORTABLE_WINDOWS.bat` — инструмент сборки для разработчика; конечному пользователю запускать его не требуется.
8. CI обязан проверять наличие EXE и встроенного `python311.dll` как в папке сборки, так и в ZIP; запуск smoke-test выполняется с ограниченным PATH, чтобы выявлять случайную зависимость от Python в системе.
9. Портативность не является основанием для удаления или отключения функций менеджера. Сохраняются анализ, инвентаризация, классификация, извлечение, SFZ-аудит, отчёты, журналирование и защитные механизмы.
10. Оригиналы пользовательской библиотеки не изменяются и не удаляются автоматически. Любые перемещения/очистка остаются за существующими проверками зависимостей, dry-run и явным подтверждением.

### Критерии приёмки

- [ ] Windows x64 CI-сборка завершается успешно.
- [ ] ZIP содержит EXE, `python311.dll`, зависимости и ресурсы.
- [ ] Smoke-test запускается без Python из PATH.
- [ ] Архив распаковывается в чистую Windows 10 x64 без установки Python.
- [ ] GUI запускается двойным щелчком и базовые операции проходят проверку.
- [ ] Аудиодекодирование и основные функции проверены на тестовом наборе форматов.
- [ ] Отдельно выполнен тест на компьютере пользователя и его реальной библиотеке; до этого нельзя заявлять о подтверждённой совместимости с его средой.

### Граница подтверждения

Решение и требования утверждены и зафиксированы в журнале проекта. Это **не** означает, что готовый Portable ZIP уже прошёл все критерии. Успех CI, наличие артефакта, запуск на чистой Windows и проверка на компьютере пользователя учитываются как отдельные этапы и подтверждаются только фактическими результатами.
