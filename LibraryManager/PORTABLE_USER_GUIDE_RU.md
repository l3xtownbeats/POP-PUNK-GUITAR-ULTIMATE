# Library Manager Portable — инструкция для Windows 10 x64

## Для пользователя

**Python на целевом компьютере не требуется.** Не устанавливай Python и не запускай `BUILD_PORTABLE_WINDOWS.bat`: этот BAT предназначен только разработчику для сборки из исходников. Тебе нужен только готовый ZIP из GitHub Actions. Внутри папки приложения находятся EXE, встроенный runtime Python 3.11 и DLL/ресурсы зависимостей. Запускай EXE двойным нажатием; не отделяй его от соседних файлов.

На компьютере, где запускается готовая сборка, **не нужно устанавливать Python, pip или PyInstaller**.

1. Скачайте ZIP-артефакт GitHub Actions с названием `POP-PUNK-GUITAR-LIBRARY-MANAGER-Windows-x64`.
2. Распакуйте архив целиком, например в `D:\\AudioTools\\LibraryManager\\`.
3. Откройте папку `POP_PUNK_GUITAR_LIBRARY_MANAGER`.
4. Запустите `POP_PUNK_GUITAR_LIBRARY_MANAGER.exe`.
5. В менеджере укажите корневую папку `Samples`, внутри которой находятся `FACTORY`, `Import Sample Guitar` и `OTHER`.

**Важно:** переносите и храните всю папку сборки целиком. Не вынимайте EXE отдельно из каталога. Для первой проверки используйте копию библиотеки или резервную копию.

## Что включено в сборку

- GUI Library Manager.
- Python runtime и необходимые зависимости, упакованные PyInstaller.
- Анализ и инвентаризация поддерживаемых материалов.
- Отчёты, SFZ-аудит, предпрослушивание WAV, review/staging и безопасные операции менеджера.

## Что не означает статус Portable

Portable означает, что Python отдельно на целевом ПК не нужен. Это не гарантирует, что каждый аудиоформат и каждая сторонняя SFZ-библиотека будут полностью совместимы. Поддержка форматов зависит от декодеров, включённых в сборку; музыкальные и сегментационные результаты остаются кандидатами до прослушивания и проверки.

## Сборка

ZIP формируется GitHub Actions на Windows x64. Для локальной сборки из исходников требуется Python 3.11 и зависимости из `requirements.txt` и `requirements-build.txt`; локальная сборка не требуется обычному пользователю.

Артефакт считается готовым к выдаче только после успешного завершения workflow **Library Manager Windows Package** и проверки наличия EXE внутри ZIP.
